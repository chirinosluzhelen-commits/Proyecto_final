# 🚡 SIMTELE-WEB

**Panel interactivo de prevención y monitoreo de Mi Teleférico**  
Proyecto educativo de Programación Web I.

> **Importante:** Todos los umbrales y valores utilizados son simulaciones didácticas y no representan límites operativos reales de Mi Teleférico.

## Integrantes

- Luz Helen Chirinos Chambi

## Módulos

1. **Detención de emergencia:** calcula la distancia de detención utilizando la velocidad y el tiempo de reacción, y muestra un aviso según un umbral ficticio.

2. **Mantenimiento:** permite agregar, visualizar y eliminar registros de mantenimiento mediante un arreglo de objetos.

3. **Viento y oscilación:** registra cinco mediciones simuladas de viento y calcula el promedio, el valor máximo y su clasificación.

4. **Sensores:** permite registrar sensores y validar sus códigos mediante la expresión regular ` /^SEN-\d{3}$/ `.

## Instrucciones de uso

1. Abrir el archivo `index.html` en un navegador.
2. Utilizar el menú de navegación para acceder a los cuatro módulos.
3. Completar los formularios con los datos solicitados.
4. Presionar los botones para realizar los cálculos o registrar información.
5. Consultar los resultados y las tablas que aparecen en cada módulo.
